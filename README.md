# ReplyReady mini-site

A no-build, responsive landing page for a KSh 300 digital product: ready-made customer replies and promotional messages for small businesses.

## Launch checklist
1. In `index.html`, set `SELLER_WHATSAPP` to the seller's international number using digits only (Kenya example: `2547XXXXXXXX`).
2. Choose the payment method and add the payment instructions to the order message/flow.
3. Prepare the full downloadable message pack and deliver it after confirmed payment. Do not publish the full paid pack in this public repository.
4. Enable GitHub Pages in repository Settings → Pages → Deploy from branch → `main` / `/(root)`, or connect this repo to a hosting provider.

This first version intentionally uses no database, API keys, paid services, or third-party scripts. Supabase is not needed for a static page that does not collect or store customer data.
